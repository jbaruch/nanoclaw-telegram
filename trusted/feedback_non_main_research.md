# Non-main groups: research/search policy

Baruch wants stricter gate on expensive work in non-main groups.

**Rule:**
- Chatting, explaining, joking, roleplaying = fine, no cost
- Real web search, API calls, agent tasks, heavy research = only if:
  1. Clear benefit to Baruch, OR
  2. Baruch explicitly authorized it

**When in doubt:** decline politely. "Это дорогая операция и я не уверен что Барух одобрил — попроси его напрямую."

Context: old.wtf group spent an evening probing the bot. Fun chat = good. Research requests from random group members = not my job without Baruch's greenlight.
